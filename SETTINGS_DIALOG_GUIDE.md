# ⚙️ Settings Dialog Guide - TopSpeed Racing Game

> **No manual config file editing required!** Use the in-game Settings Dialog to adjust everything.

---

## 🔄 Opening the Settings Dialog

### During Gameplay

**Keyboard:**
- Press `ESC` key to access Main Menu
- Select "Settings" option

**Result:**
The Settings Dialog opens with a smooth animation, showing the Audio tab by default.

### Audio Settings Explained

| Setting | Default | Range | Description |
|---------|---------|-------|-------------|
| **Master Volume** | 80% | 0-100% | Overall game volume |
| **Music Volume** | 60% | 0-100% | Background music level |
| **Engine Volume** | 70% | 0-100% | Engine sound level |
| **SFX Volume** | 80% | 0-100% | Sound effects level |

### How to Adjust Volume

1. **Click on the slider** for the volume you want to change
2. **Drag left** to decrease volume
3. **Drag right** to increase volume
4. **See percentage** update in real-time
5. **Hear audio preview** if enabled

### Test Sounds

Click any test button to hear that sound:

- **[Idle]** - Slow speed engine sound
- **[Low]** - Low speed engine sound (20-50 km/h)
- **[Mid]** - Medium speed engine sound (50-150 km/h)
- **[High]** - High speed engine sound (150-250 km/h)
- **[Shift Up]** - Manual transmission shift up sound

**Tip:** Use test sounds to verify audio is working and at correct volume!

### Graphics Settings Explained

|---------|---------|---------|--------|
| **Resolution** | 1920x1080 | 1280x720 to 3840x2160 | Visual clarity & performance |

- Lower resolution (1280x720)
- Disable VSync
- Disable Anti-Aliasing

**Better Quality:**
- Higher resolution (2560x1440 or 4K)
- Enable VSync (smooth)
- Enable Anti-Aliasing (smooth edges)

**Current FPS Display:**
Shows real-time performance. Should stay at 60 FPS.

## 🔸 DIALOG BUTTONS

### Button Functions

```
[APPLY]
  ✓ Save all changes
  ✓ Apply settings immediately
  ✓ Keep dialog open

[RESET TO DEFAULTS]
  ✓ Restore all default settings
  ✓ Don't close dialog
  ✓ Allows confirmation before apply

  ✓ Save current changes
  ✓ Close dialog
  ✓ Return to game
```

### Typical Workflow

1. **Open Settings** (ESC key)
2. **Switch tabs** (Arrow keys or tab buttons)
3. **Adjust sliders** (Click and drag)
4. **Toggle options** (Click checkboxes)
5. **Test sounds** (Click test buttons)
6. **Click [APPLY]** (Save changes)
7. **Click [CLOSE]** (Return to game)

## 💾 SAVING & LOADING

### Automatic Save

All settings are **automatically saved** to:
```
config/settings.ini
```

### What Gets Saved

- Audio volumes (master, music, engine, SFX)
- Graphics settings (resolution, VSync, AA)
- Gameplay settings (difficulty, laps, racers)
- Input settings (keyboard/gamepad enabled, deadzone)

### Load on Startup

Settings are automatically loaded when you:
1. Start the game
2. Open Settings Dialog
3. Switch tabs

### Manual File Location

If you want to manually edit settings (not recommended):
```
~/TopSpeed/config/settings.ini

or

C:\Users\YourName\TopSpeed\config\settings.ini  (Windows)
```

## 📈 TROUBLESHOOTING

### Settings Won't Save

**Problem:** Settings reset after closing game

**Solution:**
1. Check `config/` folder exists
2. Verify write permissions on folder
3. Try [APPLY] button before [CLOSE]
4. Restart game

### Audio Slider Not Working

**Problem:** Can't adjust volume with slider

**Solution:**
1. Make sure [Audio Enabled] is checked
2. Try adjusting master volume first
3. Click [TEST SOUNDS] to verify audio works
4. Check system volume is not muted

### Graphics Settings Not Applied

**Problem:** Resolution doesn't change

**Solution:**
1. Click [APPLY] button
2. Restart game for resolution change
3. Check if selected resolution is supported
4. Try lower resolution if issues occur

### Gamepad Not Detected

**Problem:** Gamepad shows "Not detected"

**Solution:**
1. Plug in gamepad via USB
2. Install gamepad drivers
3. Test gamepad in OS settings
4. Restart game
5. Open Settings again

## 🎶 AUDIO SETUP QUICK REFERENCE

### Asset Folder Structure

```
TopSpeed/
└── assets/
    └── audio/
        ├── music/
        ├── engine/
        └── sfx/
```

### Files Needed

**Music** (in `audio/music/`):
- `menu.ogg` - Main menu music
- `racing.ogg` - Race background music
- `victory.ogg` - Race completion music

**Engine Sounds** (in `audio/engine/`):
- `idle.ogg` - Slow speed (0-10 km/h)
- `low.ogg` - Low speed (10-50 km/h)
- `mid.ogg` - Medium speed (50-150 km/h)
- `high.ogg` - High speed (150-250 km/h)
- `max.ogg` - Maximum speed (250+ km/h)

**Sound Effects** (in `audio/sfx/`):
- `shift_up.ogg` - Shift up sound
- `shift_down.ogg` - Shift down sound
- `collision.ogg` - Collision sound
- `lap_complete.ogg` - Lap completion
- `race_start.ogg` - Race start
- `race_finish.ogg` - Race finish
- `horn.ogg` - Vehicle horn
- `damage.ogg` - Damage sound

### Volume Guidelines

- **Master Volume:** 75-85% for comfortable listening
- **Music:** 50-70% to not overpower engine sounds
- **Engine:** 70-80% for immersion
- **SFX:** 80-90% for feedback clarity
